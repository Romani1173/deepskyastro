# Origen de la portada

La portada del artículo «Mapejant les regions actives del Sol amb PixInsight»
fue generada específicamente para este porfolio mediante OpenAI ImageGen el
26 de julio de 2026.

No se utilizó ni se incorporó ninguna fotografía externa como referencia,
entrada o material de partida. La imagen no procede de una web, un fotógrafo
ni un banco de imágenes.
